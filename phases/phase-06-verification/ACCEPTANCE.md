# Phase 6 — Acceptance Criteria

- [ ] No task is marked complete without passing its verification steps.
- [ ] Verification retries are bounded and fully observable in events and logs.
- [ ] Failures cascade-cancel dependents with clear reasons.
- [ ] Interrupted runs resume from persisted state without redoing completed work.
- [ ] Deterministic suite passes offline; live suite remains opt-in and skipped
  by default.
