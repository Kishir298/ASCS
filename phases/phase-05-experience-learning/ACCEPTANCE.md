# Phase 5 — Acceptance Criteria

- [ ] Completed runs record structured experiences (plan, actions,
  verification, score).
- [ ] Later runs retrieve language/toolchain/error-relevant past strategies
  within a bounded prompt budget.
- [ ] Contradicted successes are penalized and stop being recommended.
- [ ] Store stays bounded, survives corrupt lines, and never blocks a run.
- [ ] Enable/disable/path controls (`AGENT_EXPERIENCE_ENABLED`,
  `AGENT_EXPERIENCE_PATH`) work as documented.
